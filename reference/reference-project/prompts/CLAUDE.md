# Prompts

Record of the prompts used throughout the project. Each file documents a relevant prompt with context, steering criteria, and a critical assessment of the result.

## Naming convention

`NN-prompt-name.md` — sequential, lowercase, hyphens. Example: `00-data-modeling.md`.

## Structure of each file

| Section | What to record |
|---|---|
| **Goal** | What the prompt solves or produces |
| **Context** | Where and why it was used |
| **Prompt** | Exact text sent to the AI |
| **Steering Criteria** | Engineering decisions behind the prompt — why it was structured this way |
| **Result** | What the AI produced and a critical assessment: kept, discarded, revised |
| **Revisions** | Iterations and the reason, if any |

## When to record

- AI-assisted architecture decisions
- Generation of models, schemas, or code stubs
- Queries that produced output used directly in the project
- Any prompt where steering and critical review added value to the result

The goal is not volume — it's traceability and judgment.
